# Google 학교 계정 로그인 · 비밀번호 재설정

로그인/회원가입 화면의 **"Google 학교 계정으로 로그인/가입"** 버튼과 **"비밀번호를 잊으셨나요?"** 링크.

## 동작
* Google 로그인은 학교 메일(`@hanilgo.cnehs.kr`) 계정만 받는다(계정 선택 창도 학교 도메인을 먼저 보여줌).
  처음 들어온 계정이면 이메일 가입과 똑같은 규칙(`identityFromEmail`: 학번 → 학년/반/번호, 담임·방문자 예외)으로 사용자 정보를 만든다.
  학교 메일이 아니거나 가입할 수 없는 번호면 방금 생긴 Firebase 계정을 지우고 로그아웃한 뒤 안내한다.
* 이미 이메일·비밀번호로 가입한 메일로 Google 로그인하면 **같은 계정**으로 들어가 기존 데이터(프로필·XP 등)를 그대로 쓴다.
  - Firebase 가 자동으로 합치는 경우: 학교 메일이 Google Workspace 라면 Google 이 그 메일의 공식 확인자라서 같은 계정에 연결된다.
    이때 메일 인증을 안 한 계정은 Firebase 가 기존 비밀번호 로그인을 끌 수 있다 → "비밀번호를 잊으셨나요?" 로 비밀번호를 다시 정하면 둘 다 쓸 수 있다.
  - 자동으로 안 합쳐지는 경우(`account-exists-with-different-credential`): 비밀번호를 한 번 물어본 뒤 그 계정에 Google 로그인을 연결한다.
* 팝업이 막힌 브라우저에서는 페이지 이동 방식(redirect)으로 로그인하고, 돌아오면 마무리한다.
* 비밀번호 재설정: 입력해 둔(또는 새로 입력한) 메일로 Firebase 재설정 메일을 보낸다. 메일은 한국어(`auth.languageCode = 'ko'`).

## Firebase 콘솔에서 할 일 (한 번)
1. **Authentication → 로그인 방법(Sign-in method) → Google 사용 설정**(프로젝트 지원 메일 선택 후 저장).
   꺼져 있으면 버튼을 눌렀을 때 "이 로그인 방식이 아직 켜져 있지 않아요" 안내가 뜬다.
2. **Authentication → 설정 → 승인된 도메인**에 사이트 주소를 추가한다(예: `one-2comunity-test.onrender.com`, 실제로 쓰는 도메인 모두).
   없으면 "이 사이트 주소가 Google 로그인 허용 도메인에 없어요" 안내가 뜬다.
3. (선택) **Authentication → 설정 → 사용자 계정 연결**은 기본값 "같은 이메일은 한 계정"을 유지한다(바꾸면 같은 메일로 계정이 둘 생긴다).
4. (선택) **Authentication → 템플릿 → 비밀번호 재설정** 문구/보내는 이름을 다듬는다.

비밀번호 재설정 메일은 Email/Password 로그인이 켜져 있으면 따로 설정 없이 동작한다.
Firestore 규칙은 바꿀 필요 없다(새 계정의 `users/{uid}` 거울은 기존 규칙의 본인 create 로 만들어진다).
