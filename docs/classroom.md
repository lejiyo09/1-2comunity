# 구글 클래스룸 과제 위젯 · 플래너 사진 읽기

## 1) 구글 클래스룸 과제 위젯 (홈 → "📚 클래스룸 과제")

학생 본인의 Google 계정으로 연결해서 **내 과제를 마감 순으로** 보여 주는 위젯이다. 읽기 전용이고, 우리 사이트는 비밀번호를 받지 않는다(Google 로그인 창에서 처리).

* 요청하는 권한(범위): `classroom.courses.readonly`(수강 중인 수업 목록), `classroom.coursework.me.readonly`(내 과제와 제출 상태). 선생님 권한/다른 학생 정보는 요청하지 않는다.
* 액세스 토큰은 **메모리에만** 두고 서버로 보내지 않는다(새로고침하면 사라져서 "새로고침"으로 다시 연결). 불러온 과제 목록만 이 브라우저에 계정별로 캐시해서, 연결 없이도 마지막 목록을 보여 준다. "연결 해제"를 누르면 토큰을 폐기하고 캐시를 지운다.
* 제출한 과제는 숨기고, 마감이 한 주 넘게 지난 과제도 숨긴다. 각 과제의 "＋ 할 일"을 누르면 플래너 오늘 할 일에 `[수업] 제목`으로 들어간다.

### 켜는 방법 (사이트 운영자가 한 번만)

위젯은 **OAuth 클라이언트 ID가 비어 있으면 "준비 중"** 으로 보인다. 아래 순서로 ID를 만들어 `index.html` 의 `GOOGLE_CLIENT_ID` 상수(`id="classroom-widget-script"` 스크립트 맨 위)에 넣고 배포한다.

1. [Google Cloud Console](https://console.cloud.google.com/) → 새 프로젝트 만들기
2. **API 및 서비스 → 라이브러리 → Google Classroom API → 사용**
3. **OAuth 동의 화면** 설정
   * 사용자 유형: 프로젝트가 **학교 Google Workspace 조직 소속**이면 *내부*(학교 계정만, 검수 없음). 개인 계정으로 만든 프로젝트면 *외부*만 가능하다.
   * *외부*이고 게시 상태가 "테스트 중"이면 **테스트 사용자로 등록한 계정만**(최대 100명) 쓸 수 있고, 로그인 권한이 7일마다 만료된다. 전체 학생이 쓰게 하려면 "프로덕션으로 게시"해야 하는데, Classroom 범위는 *민감한 범위*라 Google 앱 검수가 필요할 수 있다.
   * 범위에 위 두 개(`.../auth/classroom.courses.readonly`, `.../auth/classroom.coursework.me.readonly`)를 추가한다.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션**
   * **승인된 JavaScript 원본**에 사이트 주소(예: `https://one-2comunity-test.onrender.com`)를 넣는다. (여러 배포 주소를 쓰면 각각 추가)
5. 만들어진 클라이언트 ID(`...apps.googleusercontent.com`)를 `GOOGLE_CLIENT_ID` 에 붙여넣는다. (비밀 값이 아니라 공개되어도 되는 ID다. **클라이언트 보안 비밀번호는 넣지 않는다.**)

### 학교 계정(Google Workspace)이라면
학교 관리자가 **외부 앱의 Google API 접근을 막아 둔 경우** 학생이 연결해도 "접근이 허용되지 않았어요"(403/`access_blocked`)가 뜬다. 관리자 콘솔 → 보안 → API 제어 → *앱 액세스 제어*에서 이 OAuth 클라이언트를 허용(신뢰)해야 한다. 이건 코드로 해결할 수 없다.

### 확인 방법
홈의 클래스룸 위젯 → "Google 클래스룸 연결" → Google 로그인/허용 → 과제 목록이 보이면 성공. 오류 문구(권한 없음/만료/팝업 차단)는 위젯에 그대로 안내된다.

## 2) 플래너 사진 읽기 (베타) (플래너 → "기능들" → "📷 플래너 사진 읽기")

종이 플래너를 찍은 사진에서 글자를 읽어 **할 일 목록 초안**으로 가져온다.

* 글자 인식은 [Tesseract.js](https://github.com/naptha/tesseract.js)(한국어+영어)를 처음 쓸 때 CDN 에서 내려받아 **이 브라우저 안에서만** 돌린다. 사진은 서버로 보내지 않는다.
* 사진을 고르면 크기를 맞추고, 읽을 곳("할 일 목록 부분(왼쪽 위)" 또는 "사진 전체")을 잘라 흑백/밝기 보정한 뒤 인식한다. 머리말(TO DO, YEAR/MONTH/DAY, D-DAY …), 기호/숫자만 있는 줄, 줄 앞의 번호·체크박스 기호는 걸러낸다.
* 읽은 줄은 **항상 사람이 확인·수정**하고 체크한 줄만, 고른 날짜(오늘 이후)의 할 일로 추가된다(과목은 첫 번째 과목, 목표 30분).
* **한계**: 손글씨는 틀리게 읽히거나 못 읽을 수 있다(또박또박 쓴 글씨, 밝고 반듯한 사진일수록 잘 된다). **시간표(타임테이블) 칸의 색칠, D-DAY/날짜 칸은 읽지 않는다.** 이 모델을 우리 반 글씨로 "학습"시키는 기능은 없다 — 정확도를 더 올리려면 실제 플래너 사진 샘플로 영역 위치/전처리를 맞추는 작업이 따로 필요하다.
